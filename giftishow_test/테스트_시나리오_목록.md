우선순위 High부터 Page Object 작성:

# pages/product_page.py - GS_PRODUCT_001~003

# pages/order_page.py - GS_ORDER_001~004

## 💡 시나리오 추가/수정 가이드

### 새 시나리오 추가
1. Google Sheets의 `TestCase_Scenarios` 시트 열기
2. 새 행 추가
3. 컬럼 작성:
   - TC ID: 카테고리 접두어 + 일련번호 (예: GS_PRODUCT_006)
   - Category: 카테고리명
   - Scenario Name: 시나리오 제목
   - Pre-condition: 선행 조건
   - Test Steps: 단계별 설명
   - Locators: UI 요소 식별자
   - Expected Result: 예상 결과
   - Priority: High/Medium/Low
   - Automation Status: Pending
   - Note: 추가 정보

### 시나리오 수정
- Google Sheets에서 직접 수정
- 변경 내역은 자동 저장됨
- Note 컬럼에 수정 일자 및 이유 기록 권장
