## 🔧 Locator 수정 가이드

현재 구현은 **일반적인 로그인 페이지 구조**를 가정하고 작성되었습니다.
**실제 기프티쇼 웹사이트**에 맞게 Locator를 수정해야 합니다.

### Locator 확인 방법

#### 방법 1: Chrome DevTools 사용 (권장)

1. **기프티쇼 로그인 페이지 접속**
   ```
   https://biz.giftishow.com/login
   또는
   https://biz.giftishow.com/signin
   ```

2. **F12 키** 눌러 개발자 도구 열기

3. **Elements 탭** → **Select element (Ctrl+Shift+C)**

4. **각 요소 클릭해서 확인**:
   - ID 입력 필드 클릭 → HTML 코드 확인
   - 비밀번호 입력 필드 클릭 → HTML 코드 확인
   - 로그인 버튼 클릭 → HTML 코드 확인

#### 예시: ID 입력 필드 확인

HTML 코드가 이렇게 생겼다면:
```html
<input type="text" id="user_id" name="userId" class="input-field" />
```

Locator는:
- `By.ID` → `"user_id"`
- `By.NAME` → `"userId"`
- `By.CLASS_NAME` → `"input-field"`
- `By.CSS_SELECTOR` → `"input[type='text']"` 또는 `"#user_id"`

### Locator 수정하기

`pages/login_page.py` 파일을 열어서 수정:

```python
# ==================== Locators ====================
# 현재 (예시)
USERNAME_INPUT = (By.ID, "username")
PASSWORD_INPUT = (By.ID, "password")
LOGIN_BUTTON = (By.CSS_SELECTOR, "button[type='submit']")

# 실제 웹사이트에 맞게 수정
USERNAME_INPUT = (By.ID, "실제_ID_필드_아이디")
PASSWORD_INPUT = (By.NAME, "실제_비밀번호_필드_이름")
LOGIN_BUTTON = (By.XPATH, "//button[contains(text(), '로그인')]")
```

### 자주 사용하는 Locator 패턴

```python
# ID로 찾기 (가장 안정적)
(By.ID, "login_btn")

# Name으로 찾기
(By.NAME, "username")

# Class로 찾기
(By.CLASS_NAME, "btn-primary")

# CSS Selector로 찾기
(By.CSS_SELECTOR, "button.btn-login")
(By.CSS_SELECTOR, "#login_form input[type='password']")

# XPath로 찾기 (복잡하지만 강력)
(By.XPATH, "//button[@id='login']")
(By.XPATH, "//input[@placeholder='아이디']")
(By.XPATH, "//div[contains(@class, 'error-message')]")
```

### 에러 메시지 Locator 확인

로그인 실패 후 표시되는 에러 메시지도 확인:

```python
# 현재 (예시)
ERROR_MESSAGE = (By.CLASS_NAME, "error-message")

# 실제 HTML에 맞게 수정
ERROR_MESSAGE = (By.CSS_SELECTOR, ".alert-danger")
ERROR_MESSAGE = (By.XPATH, "//div[@class='error-msg']")
```

## 🐛 테스트 실행 후 디버깅

### 시나리오 1: 요소를 찾을 수 없음

```
selenium.common.exceptions.NoSuchElementException:
Message: no such element: Unable to locate element: {"method":"id","selector":"username"}
```

**원인**: Locator가 실제 웹사이트와 다름

**해결**:
1. Chrome DevTools로 실제 요소 확인
2. `pages/login_page.py`에서 해당 Locator 수정
3. 재실행

### 시나리오 2: 로그인은 되는데 확인 실패

```
AssertionError: 로그인 실패: 메인 페이지로 이동하지 못했습니다
```

**원인**: 로그인 성공 확인 로직이 실제와 다름

**해결**: `pages/login_page.py`의 `is_logged_in()` 메서드 수정

```python
def is_logged_in(self, timeout=10):
    """로그인 성공 확인"""
    # 실제 기프티쇼 사이트에 맞게 수정

    # 옵션 1: URL 확인
    current_url = self.get_current_url()
    if "main" in current_url or "dashboard" in current_url:
        return True

    # 옵션 2: 특정 요소 확인 (로그인 후에만 보이는 요소)
    USER_MENU = (By.CLASS_NAME, "실제_사용자메뉴_클래스")
    if self.is_element_visible(USER_MENU, timeout=5):
        return True

    return False
```

### 시나리오 3: 에러 메시지가 표시 안 됨

```
Warning: Error message not displayed
```

**원인**:
- 에러 메시지 Locator가 틀림
- 또는 웹사이트가 다른 방식으로 에러 표시 (예: alert, toast)

**해결**:
1. 실제 로그인 실패 시 에러가 어떻게 표시되는지 확인
2. Locator 수정

### 시나리오 4: 로그인 페이지 URL이 다름

```
현재: https://biz.giftishow.com/login
실제: https://biz.giftishow.com/account/signin
```

**해결**: `pages/login_page.py`의 `__init__` 메서드 수정

```python
def __init__(self, driver, base_url=None):
    super().__init__(driver)
    # ...
    self.login_url = f"{self.base_url}/account/signin"  # 실제 URL로 수정
```
