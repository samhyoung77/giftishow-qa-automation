## ⏭️ GS_AUTH_001: 정상 로그인 (자동화 불가)

### 자동화 불가 이유

1. **Akamai Bot Manager** 감지
   - Selenium을 자동화 도구로 인식
   - 로그인 버튼 클릭 시 차단
   - undetected-chromedriver로도 우회 어려움

2. **2단계 인증 (2FA)**
   - 카카오톡으로 인증번호 전송
   - 인증번호 입력 자동화 불가능
   - 사람이 직접 확인 및 입력 필요

3. **수동 개입 필요**
   - `manual_login.py` 스크립트 제공
   - 한 번 로그인 → 쿠키 저장 → 재사용 방식
   - 하지만 자동화 테스트로 적합하지 않음

**결론**: ⏭️ **SKIPPED 처리**

```python
@pytest.mark.skip(reason="2FA(카카오톡 인증) + Akamai Bot Manager로 인해 자동화 불가능")
def test_successful_login(self, driver, test_data):
```
