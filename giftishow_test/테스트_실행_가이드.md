## 3. 테스트 실행 방법

### 3-1. GS_PRODUCT_001: 상품 카테고리 조회 테스트

Menu_tree_check_list의 카테고리 URL을 테스트하고 상품 상세 페이지 접근을 확인합니다.

```bash
cd E:\claude_code\giftishow_test

# 전체 카테고리 테스트 (30개)
python -m tests.test_category_urls --headless

# 최대 N개 카테고리만 테스트
python -m tests.test_category_urls --max 5 --headless

# 특정 레벨만 테스트 (1: 대분류, 2: 중분류, 3: 소분류)
python -m tests.test_category_urls --level 1 --headless

# 브라우저 보면서 테스트 (디버깅용)
python -m tests.test_category_urls --max 3
```

**테스트 항목**:
- 카테고리 페이지 로딩 확인
- 상품 목록 표시 확인
- 상품 클릭 시 상세 페이지 이동 확인

**결과 기록**:
- TestResults 탭에 각 카테고리별 PASS/FAIL 기록
- Menu_tree_check_list J열(Result), K열(Error Message) 업데이트

---

### 3-2. GS_PRODUCT_002: 상품 검색 테스트

검색 기능을 테스트합니다 (키워드 검색, 인기 검색어 클릭 등).

```bash
cd E:\claude_code\giftishow_test

# 전체 시나리오 테스트 (17 Steps)
python -m tests.test_product_search --full-scenario --headless

# 개별 키워드 테스트
python -m tests.test_product_search --keywords 스타벅스 커피 --headless

# 검색 버튼 클릭 방식으로 테스트
python -m tests.test_product_search --keywords 스타벅스 --method button --headless

# 브라우저 보면서 테스트 (디버깅용)
python -m tests.test_product_search --full-scenario
```

**전체 시나리오 (--full-scenario) 테스트 항목**:
| Step | 테스트 내용 |
|------|------------|
| 1-4 | 키워드 '스타벅스' + 검색 버튼 클릭 |
| 5-8 | 키워드 '생일' + Enter 입력 |
| 9-11 | 쿠폰 인기 검색어 첫번째 항목 클릭 |
| 12-14 | 판촉 인기 검색어 첫번째 항목 클릭 |
| 15-17 | 키워드 '가나다라마바사아자차카타파하' (결과 없음 확인) |

**결과 기록**:
- TestResults 탭에 각 Step별 PASS/FAIL 기록
- TestCase_Scenarios의 GS_PRODUCT_002 상태 업데이트

### 3-4. 수동 로그인 (2FA 인증용)

자동 로그인이 불가능한 경우 수동으로 로그인하여 쿠키를 저장합니다.

```bash
cd E:\claude_code\giftishow_test

# 수동 로그인 실행
python manual_login.py
```

**사용 방법**:
1. 브라우저가 열리면 로그인 진행 (카카오톡 2FA 인증 포함)
2. 로그인 완료 후 터미널에서 Enter 입력
3. 쿠키가 자동 저장됨 (`cookies/giftishow_cookies.json`)

## 5. 고급 사용법

### 5-1. 테스트 옵션 정리

**test_category_urls.py 옵션**:
| 옵션 | 설명 | 예시 |
|------|------|------|
| `--max N` | 최대 N개 카테고리만 테스트 | `--max 5` |
| `--level N` | 특정 레벨만 테스트 (1,2,3) | `--level 1` |
| `--headless` | 브라우저 숨김 모드 | `--headless` |

**test_product_search.py 옵션**:
| 옵션 | 설명 | 예시 |
|------|------|------|
| `--full-scenario` | 전체 17 Steps 테스트 | `--full-scenario` |
| `--keywords` | 특정 키워드만 테스트 | `--keywords 스타벅스 커피` |
| `--method` | 검색 방법 (enter/button) | `--method button` |
| `--headless` | 브라우저 숨김 모드 | `--headless` |

---

### 5-2. 병렬 실행 (pytest)

```bash
# 4개 프로세스로 병렬 실행
pytest tests/ -n 4 -v

# CPU 코어 수만큼 자동
pytest tests/ -n auto -v
```

---

### 5-3. 실패 시 재시도

```bash
# 실패 시 2번 재시도
pytest tests/ --reruns 2 -v

# 재시도 전 1초 대기
pytest tests/ --reruns 2 --reruns-delay 1 -v
```

---

### 5-4. 특정 조건으로 실행

```bash
# 실패한 테스트만 재실행
pytest --lf -v

# 처음 실패 시 중단
pytest -x -v

# N번 실패 시 중단
pytest --maxfail=3 -v
```

## 6. 문제 해결

### 문제 1: "Chrome not found"

**원인**: ChromeDriver가 설치 안 됨

**해결**:
```bash
# Chrome 브라우저만 설치되어 있으면 webdriver-manager가 자동 다운로드
# Chrome 설치 확인
chrome --version
```

---

### 문제 2: "Module not found"

**원인**: 라이브러리 설치 안 됨

**해결**:
```bash
# 전체 재설치
pip install -r requirements.txt
```

---

### 문제 3: Google Sheets 연결 오류

**원인**: credentials.json 없거나 권한 없음

**해결**:
1. `credentials.json` 파일 확인
2. Google Sheets 공유 설정 확인
3. 서비스 계정 이메일에 편집자 권한 부여

---

### 문제 4: 인기 검색어 클릭 실패

**원인**: 검색 패널이 열리지 않음

**해결**: 최신 스크립트 사용 (검색 버튼 클릭 후 인기 검색어 찾기 로직 적용됨)

---

### 문제 5: 로그인 필요한 테스트

**원인**: 2FA(카카오톡 인증) + Akamai Bot Manager로 자동 로그인 불가

**해결**:
```bash
# 수동 로그인으로 쿠키 저장
python manual_login.py
```
